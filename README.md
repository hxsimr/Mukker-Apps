# Mukker Apps

Offline-first apps by Harsimran, hosted on GitHub Pages.

| App | URL |
| --- | --- |
| Home | https://hxsimr.github.io/Mukker-Apps/ |
| Mukker Tasks (pixel) | https://hxsimr.github.io/Mukker-Apps/tasks-pixel/ |
| Mukker Tasks (black) | https://hxsimr.github.io/Mukker-Apps/tasks-black/ |

Each app is a static PWA. On iPhone, open the link in Safari and use Share → Add to Home Screen. Tasks are saved on the device and the app works offline after the first visit.

Preview locally from this folder:

```bash
python3 -m http.server 8000
```

Then open <http://localhost:8000/>, <http://localhost:8000/tasks-pixel/>, and <http://localhost:8000/tasks-black/>.
